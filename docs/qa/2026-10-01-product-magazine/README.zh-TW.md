# 2026-10-01 商品頁改版（雜誌式版面）

使用者 2026-10-01：「商品頁的 layout 要改版，分析 https://jakobsencopenhagen.com/en/products/holger-1-5-seater 並高度學習。我喜歡他像雜誌排版的版面設計；情境圖縮圖極簡統一，無贅字；但我們素材不多，可以精簡一點上下幅的介紹。」

## 參考頁的版面（1440×900 截圖＋DOM 量測）
- 12 欄格線、窄留白。左邊一張直式大圖（約佔 47% 寬、整個視窗高），捲動時固定不動；右欄從 64% 處開始。
- 右欄最上面是一排 56×65 的小縮圖（只有圖、間距 6px、作用中一圈細框）；中間大量留白；品名（18px）、一段短文、兩三列細線規格、兩顆整欄寬的按鈕落在首屏底部。往下才是尺寸表、線稿與材質。
- 第二段是情境圖：同一套格線上放大小不同的圖（左大右中、兩張小直圖配一張大橫圖），沒有圖說。
- 最後是三欄直式商品卡。字級都小（12–18px），沒有大標題區塊。

## 本站的做法
- `ProductGallery`（client）改為整個首段的骨架：左 1–6 欄的大圖 `position: sticky`，右 8–12 欄；右欄首屏（`.product-first`）上面是縮圖、下面是品名／價格／一句摘要／一段說明／同系列選項／加入購物車，高度等於大圖，所以按鈕貼齊首屏底部。其後接規格表（保留細線）與禮盒說明。
- 縮圖：56×68、`object-fit: cover`、只有圖片，作用中是 1px 墨色外框。原本的「01 / 03 禮盒情境」文字、左右箭頭列、「放大查看」字樣都拿掉（放大改成右下角一個「+」）。
- 大圖：直式照片填滿（cover）；方形或橫式照片完整顯示（contain），避免把商品裁掉。
- 情境圖段（`.product-story--0…3`）：除了第一張以外的圖依張數排成不同版面——1 張：左半；2 張：左大、右上中圖、文字在右下；3–4 張：再加一列，左邊文字（上方可放一張小圖）、右邊大圖。沒有圖說。故事只留一個小標題與一段文字（茶類保留兩枚獎項標）。
- 精簡：拿掉麵包屑列、「01 / THE DETAILS」「02 / IN EVERYDAY LIFE」大標題區塊與重複的摘要、上一款／下一款區塊；「繼續觀看」標題縮小。
- 底部固定列：頁面內的加入購物車按鈕在畫面上時收起，捲過之後才出現。
- 手機：大圖滿版在最上面，縮圖一排，文字、規格依序；情境圖單欄，中間兩張並排。
