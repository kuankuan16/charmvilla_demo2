# 2026-10-12 茶葉禮盒商品圖統一

使用者要求：四張圖裡的禮盒看起來一樣大；圖二俯視圖放大並加淡淡陰影；圖三不要大到出血；四張背景統一同一種灰色漸層（不偏黃、不偏紅）。

## 作法（沒有用 AI 重新生成）

- `norm.py` 從原圖算出背景漸層與商品範圍，把背景換成同一個中性灰漸層 `#e8e7e5 → #dbdad8`（左上→右下），保留原本的陰影（用「比原背景暗多少」的倍率疊回去），商品像素不動。
- 大小用「商品實際面積」統一（面積開根號＝畫面寬 45%），另外限制寬度不超過 80%、高度不超過 52%，所以不會出血。
- 圖二原本是去背圖，加上一層模糊、往右下偏移、16% 深的淡陰影。
- 輸出 1856×2320（4:5），檔名在原檔名後加 `-even`；原圖保留不動。`src/data/catalog.ts` 的 `evenGalleryFiles` 清單決定哪些圖改用 `-even` 版。
- 團圓桐木盒開箱照（目前粉紅色選項下架，網站上看不到）背景有暗角，用手動多邊形補商品範圍：見 `run_all.sh`。
- 重跑：`run_all.sh 0.45`（需要 Pillow、numpy、scipy 的暫存 venv；不是專案 dependency）。

## v2（`-even2`，同日晚）

使用者：「俯視圖的陰影都太假了」「這張陰影也不行」（團圓斜角照）。

- 圖二陰影：原本模糊前沒有留邊，陰影在盒子外框處被切成硬長方形。改為先留白再模糊，兩層：大範圍淡陰影（往下偏）＋貼著盒底的接觸陰影。
