## 做了什麼
- **Preloader**：金色半邊加回 `/brand/goldfish-white.svg`（位置與 09-29 版相同：left 38%、垂直置中、寬 28%）。
- **合作夥伴文字**：`.partners-statement` 與 `.craft-quote` 同一組數值（`clamp(24px, 2.5vw, 42px)`／500／行高 1.35；1440 寬時 36px），平板與手機的縮放也一起跟。原本是 40px 粗體。
- **流暢度**（量測腳本：在首頁以滑鼠滾輪捲 11,000px，同時移動游標，CDP `Performance.getMetrics`）：
  1. 金魚游標：原本每一格把位置寫成 `<html>` 上的兩個 CSS 變數，瀏覽器因此每秒 60 次重算**整份文件**的樣式，而且游標停住後也不會停。改成直接寫在游標元素自己的 `transform`，追上指標後就停止更新。
  2. 以手成形：原本每一格都量尺寸並寫一個 CSS 變數；改成只在版面改變時量、只在捲動事件時計算。
  3. 以手成形的停留距離：每張卡 55svh → 30svh（手機 45 → 28），1440×900 時整段從 1,485px 縮到 810px，頁面「不動」的時間少了約 45%。
- 結果：每 1.1 秒捲動中的樣式重算時間，修正前 247–312 ms，修正後 4–17 ms。影格時間兩者中位數都是 16.7 ms（無頭瀏覽器、本機），所以「卡」的感覺主要來自真實機器上被佔掉的運算與停留距離，不是掉格；實機觀感需使用者確認。
