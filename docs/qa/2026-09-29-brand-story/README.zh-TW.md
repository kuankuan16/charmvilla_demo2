# 品牌故事第二、三屏

## 成品／交付檔
`src/components/sections/Manifesto.tsx`：品牌文字與三張影像輪播。文案在 `src/data/content.ts`，樣式在 `src/app/globals.css`。修改前檔案已保留於 before/。

## 製作方式與設定
第二屏：Our Craft，桌面文字欄寬 60.2vw，參考原站文字欄約 90.3vw 的 2/3，靠左 4.86vw。手機欄寬 86vw。逐字由 20% 至 100% 不透明度隨捲動顯色，反向捲動會還原。冷白 #F6F8FA 與原 logo 金色 #E4A038 延續第一屏。
第三屏：中央圖寬 90.5vw，兩側露出相鄰黑白圖，中央彩色。三張縮圖、5 秒自動切換，滑鼠停留與鍵盤焦點暫停；支援縮圖點選、左右方向鍵及觸控滑動。捲動停留時放大至 1.11 倍。減少動態偏好：文字直接全顯示，不自動輪播、不放大、不固定捲動。
導覽列使用冷白底，避免閱讀區的內容從選單文字背後透出。

## 參考與來源
互動參考：https://recruit.positive.co.jp/ 的 Message 與 gallery。已閱讀原站並檢視互動程式：文字 start top 80% / end bottom 80%、gallery 5 秒換圖、thumbnail progress、scroll scale-up。相片與筆刷來源、SHA-256 見 assets.json。
文案為此次撰寫，以既有茶包工藝介紹與使用者核准的獎項年份、名稱為依據。獎項明確指小金魚茶包，未擴張到其他商品。

## 已檢視／驗證
桌面 1440×900 與手機 390×844 目視確認。新區塊無橫向溢出；影像無載入失敗。縮圖點選與左右方向鍵已驗證，中央彩圖與選取狀態一致。已驗證逐字顯色、反向淡回與滾動放大。npm run check 通過（既有 3 個 img lint warnings，無 errors）。

## 限制與不宣稱
既有 about-02 是先前網站生成的手作情境圖，非新增攝影，亦不宣稱是真實製程紀錄。既有圖未重製／覆寫；瀏覽器以 object-fit 作不同尺寸裁切。此版參考原站互動重新實作，未宣稱原站引擎或全站像素相同。減少動態偏好已透過瀏覽器模擬確認：文字全顯示、固定定位取消、圖區高度為一屏。觸控滑動已實作，未在實體觸控裝置驗證。
